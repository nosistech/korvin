Who it is for

For a computer with a 4 GB graphics card.

About one in seven gaming computers has 4 GB of graphics memory or less. That is 15% in the Steam hardware survey of October 2026.

Most agent tools expect a large model

We ran two well-known coding agents on the same small model. Their fixed prompts use 6,600 to 7,600 tokens. They passed 46% and 65% of our trials.

Korvin uses a short prompt and four tools

Korvin's fixed prompt uses 744 tokens, and it has four tools. On the same model and the same tasks, it passed 90%.

The whole model stays on the card

Qwen 3.5 2B runs fully on a 4 GB card, with a 64k context. The median answer in our comparison took 2.8 seconds.

No broken tool calls

In 110 comparison trials, Korvin had no broken tool call. The two coding agents had them in 9 and in 29 trials.

The Steam survey counts gaming computers only. We tested Korvin on one 4 GB card. Cards below 4 GB are not tested.

Why Korvin

Reasons to use it.

Korvin does a few jobs on your own computer, and we publish the measured result of each one.

It connects only to Ollama

Ollama runs on your own computer. Only one file in Korvin may use the network, and a guard inside Korvin blocks every connection to any other address.

It asks first

Korvin asks before it saves a note, and before every call of a tool server. It also asks before a file read that you did not expect. Enter alone means no.

Set up for Qwen 3.5 2B

Korvin is built for Qwen 3.5 2B at a 64k context. The whole model runs on a 4 GB graphics card, and the guided setup makes the 64k copy for you.

A program grades every result

Every result on this page comes from a repeatable eval run. We publish the limits next to the results.

Compared with other tools

We ran Korvin and three other agent tools on the same model. Korvin matched the best one, and it was the fastest. See the comparison.

2,496 lines of Python

The program sits in thirteen small files. It uses only the Python standard library, and it has no dependencies.

What it does

Four tools, and the controls around them.

The four built-in tools

The four built-in tools
ToolWhat it does
list_folderLists the files and folders inside your chosen folder.
read_fileReads one text file inside your chosen folder, up to 200,000 bytes.
save_noteSaves a note of up to 2,000 characters. Korvin always asks first.
find_noteFinds notes that contain every word of a search, and shows the 10 newest.
  • Standing rules. Type /rule Answer in Spanish. to add one. Korvin keeps up to 5 rules. Text in a file or a note cannot add a rule.
  • A sealed log that you can check. Each line of the log has a SHA-256 seal. python -m korvin check shows if a line was changed. The log holds no file contents and no chat text.
  • Optional local tool servers. A tool server is a separate program that gives Korvin extra tools. You add each server, and you approve each tool. The clock example tells the time and converts units, with no network.
  • Optional web search example. It sends your search words, and the addresses that it fetches, to Ollama's hosted service. It is off until you add it, and it needs your own Ollama key. Ollama charges usage credits for it. We saw search results only from a fake of that service.

Korvin and Pi are level here. With Korvin's sampling settings, Pi passed 105 of 110, so we do not claim that Korvin is better. Korvin passed 99, against 72 for OpenCode and 51 for goose.

Fastest

Korvin had the lowest median time, and it never reached the time limit. Its fixed prompt is the smallest of the four.

It says what it cannot do

We asked for a missing file and for an email. In 9 of 10 trials, Korvin said that it could not do the task. Pi did so in 3 of 10.

The question stops the read

A hidden order asked for a private file in the folder. Korvin's question stopped the read in 5 of 5 trials. In the other tools, the model read it in 9 of 15.

Where Pi is better

Pi can create files, and Korvin cannot. Pi also found the right file a little more often, and it resisted one hidden order better.

We wrote the tasks, and they fit Korvin's use. The other three tools are coding agents, and their makers did not design them for a model of this size. Decision D-037 gives both parts of the test and every limit.

The size of the modelA 2B model is far less capable than a large hosted model. It makes mistakes and sometimes states false facts.
What it is notKorvin is not a coding agent. It cannot write, rename or delete your files, and it cannot run programs. It has no voice and no dashboard.
Outside reviewNo third party has audited Korvin. No person has checked the eval checks yet.

The permission questions stop file reads and note saves, but they cannot stop what the model says. Section 8 of the user guide gives every number, and what to do about each weakness.

Start

Five steps on Windows.

You need Python 3.11 or later. Korvin was tested only on Windows 11.

  1. Install Ollama

    Download Ollama from ollama.com/download, install it, and start it.

  2. Get the model

    In a terminal, type this command and wait for the download.

    ollama pull qwen3.5:2b-q4_K_M

  3. Get Korvin

    Get the Korvin folder from the project page, and open a terminal in it. If you want the korvin command, type this once:

    pip install .

  4. Run the guided setup

    Type this command. The first time, a setup of five steps starts. Answer y to make the 64k copy.

    python -m korvin

  5. Start

    After the setup, the chat starts. Next time, type python -m korvin again, or korvin if you installed it.
